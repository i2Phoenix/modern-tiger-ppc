# Security policy

Mac OS X Tiger is obsolete and receives no vendor security updates. This
project improves protocol interoperability; it does not make Tiger a supported
or generally safe Internet-facing operating system.

For a vulnerability in project-authored code or packaging, use a private GitHub
security advisory. Do not include private keys, passwords, target addresses,
or copied Apple binaries in an issue, advisory, log, or reproducer.

Reports should include the project version, exact Tiger build, PowerPC model,
selected components, reproducible steps, and sanitized command output. State
whether the issue affects a source build, package installation, SSH service,
Security shim, or rollback path.
